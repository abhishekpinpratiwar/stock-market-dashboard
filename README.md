# 📈 Stock Market Dashboard

An interactive stock market analytics dashboard built with Python, Streamlit, yfinance, Pandas, and Plotly.

## ✨ Features

- Interactive stock price charts and candlestick visualization
- 20-day and 50-day moving averages
- Technical analysis using RSI and MACD
- Market metrics and company fundamentals
- Stock performance comparison
- Historical price data export to CSV
- Responsive dark-themed interface

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- yfinance
- Plotly

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd Stock-Market-Dashboard
```

### 2. Create and activate a virtual environment

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Launch the dashboard

```bash
python -m streamlit run app.py
```

## 📊 Data Source

Historical stock data and company information are retrieved from Yahoo Finance using the yfinance library. Availability and accuracy may vary.
